This project is a desktop to-do list application built with Python and PyQt5, allowing users to manage daily tasks through a clean, styled GUI. Users can add new task rows, which each with a checkbox and an editable text field, mark tasks as checked, and delete any checked tasks from the list with a single click. A standout feature is the export function, which lets users save all checked tasks into a plain .txt file for easy record-keeping outside the app. The interface also includes custom-styled buttons with hover and press effects for a more polished user experience. This project demonstrates skills in GUI development with PyQt5, dynamic widget creation, event handling, and basic file I/O in Python.
